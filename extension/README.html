Cut words, not ideas.

Use your existing AI chat to condense text and review what survived. No API key or companion is needed for the chat workflow.

  1. Paste the full source. Select passages, then choose Keep wording, Keep meaning or Must cover.
  2. Set an instruction and optional word budget. Prepare the rewrite prompt, copy or insert it, and send it in your chat.
  3. Paste the completed rewrite into Reply and confirm completion. Check only verifies exact wording locally. For ideas, send the prepared check prompt and import its complete JSON reply.
  4. Inspect the evidence. Prepare a repair prompt when needed and check the next draft again.

Must cover also uses a prepared chat prompt to extract ideas. Review the returned list before rewriting. Model judgments can be wrong.

Site access

Enable ChatGPT, Claude, Gemini, Grok or DeepSeek individually. Unsupported layouts use copy/paste. Lossless never presses Send or reads cookies.

API and local CLI

For automated checks and repair, install and register the optional companion following companion/README.md. Connect it here and choose Local companion for checks. Credentials stay there.

Your text

Documents use session storage until explicitly saved locally. Saves are not encrypted or synced. Clear document removes the saved copy. The extension has no analytics or hosted collection endpoint. Sending a prepared prompt shares its text with your chat provider. Companion operations use configured providers. Their terms and privacy settings apply.
