Connect Lossless

This private preview uses a local companion so API keys, Jev credentials and subscription CLI logins stay on your computer.

  1. From the repository, run npm install and node scripts/build-extension.mjs.
  2. Load extension/dist as an unpacked extension in your browser's extension developer settings. Copy its extension ID.
  3. Follow companion/README.md in the repository to generate and explicitly register the native host for that exact ID. Registration changes browser host settings; it is never done by this extension.
  4. Set credentials in the repository's .env.local and authenticate your chosen local CLI, as described in the repository README. Never paste credentials into a conversation.
  5. Open Lossless and select Connect companion. Enable ChatGPT or Claude only if you want page import and prompt insertion.

You can try the recorded run immediately, without credentials or site access. Real-site DOM compatibility has not been validated; paste and copy remain available. A chat reply must be explicitly confirmed complete before checking. Lossless never presses Send.

Remove it

Use Clear document to delete the saved document. Remove the extension in your browser settings. Follow the companion's uninstall instructions to remove the native host registration and generated local configuration.
