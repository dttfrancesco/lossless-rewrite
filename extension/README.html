Keep ideas in the conversation.

  1. Select a passage in your chat and choose Keep meaning or Keep wording.
  2. Type a normal request, such as Shorten this to 150 words.
  3. Press Ctrl+Shift+Enter (Mac: Command+Shift+Enter) in the chat box to include the text you marked to keep and send. Alt+Shift+L (Mac: Option+Shift+L) adds /lossless to your draft without sending. Then use normal Send. With no selections, Lossless explains what to select and leaves the draft unsent.

Lossless stays hidden during ordinary chat. Use the extension icon → Selections & PDF to review passages or open a reference. Close notices with × or Escape; send receipts disappear automatically.

Ordinary messages and Shift-Enter are unchanged. Lossless uses the current site's model. An unrecognized send control leaves the prepared text for manual sending. Sending does not verify or repair the answer; word limits are requests to the model, not enforced guarantees.

Open Shortcuts in the sidebar header or ? in the inline popup for the keyboard guide.

Show kept text

After the reply finishes, press Alt+Shift+H or choose Show kept text. Press again to hide it. Amber marks matching wording from Keep wording selections; green marks matches from Keep meaning selections. This is a local text search that ignores layout whitespace, not a semantic check. Paraphrases are not located automatically. Unsupported reply layouts use the full editor.

Set up Jev

Choose Set up Jev on the sidebar's first screen for the key console and a setup command containing your extension ID. Put TYPESAFE_API_KEY in the repository's .env.local file, not in a chat. Install the local companion and choose Connect and check setup. Configuration found does not mean the key has been tested. The companion guide has platform-specific instructions.

Check a rewrite

Open Check a rewrite in the sidebar for the full editor, exact wording checks, chat-based meaning reviews, evidence, undo and repair prompts. For Jev, choose Jev · local connection in Sites and connections. The companion uses only the decision model: uncertain results stay Needs review, without a second-model call. Writing, optional idea extraction and repairs use prompts you send in your existing chat. Restart Chrome after updating the companion. Checking remains a separate step, even after setup.

Your text

Chat selections use extension session storage and are scoped to a chat tab and conversation. Clear selections removes them; closing the chat tab clears its selections. PDF files stay on your device. Selected passages, filenames and page numbers are included when you send with the Lossless shortcut or /lossless. The chosen chat provider's terms and privacy settings apply.

The PDF reader supports selectable text and files up to 25 MB. Scanned pages need OCR elsewhere. Open downloaded references in this reader; Chrome's built-in PDF viewer is not modified.

The extension has no analytics or hosted collection endpoint. Optional companion checks send necessary text to the configured decision provider. There is no hosted subscription service. Version 0.4.9 is an unpacked preview; installed provider compatibility still requires validation.
