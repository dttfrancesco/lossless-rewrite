To mark text, select it in your chat or PDF and choose Keep meaning or Keep wording. Sending includes that text in the prompt; it does not run Jev. Highlighting finds matching text, not paraphrased ideas.


Set up Jev checks
The chat model writes. Jev checks whether selected ideas survived. This preview connects Jev through a small local companion.
  1. Get a key from the TypeSafe console. In your Lossless repository, create or edit .env.local and add:
    TYPESAFE_API_KEY=your_key_here
    Keep this file private. Do not paste the key into a chat. A chat subscription does not include Jev API access.
  2. With Node 22.16+ and the repository dependencies installed, run this in the repository folder:
    Finish installing the companion
    Windows, in PowerShell:
    .\companion\local\build-launcher.ps1
.\companion\local\register.ps1
    macOS or Linux:
    sh companion/local/register.sh
    Already installed? Skip generation and registration. The installed host must match this extension ID. See the companion guide for prerequisites and troubleshooting.
  3. No connection checked yet.
Then open Check a rewrite → Sites and connections and choose Jev · local connection. Add the source and finished reply to check them. Uncertain checks stay “Needs review”; no second model is called.
Connecting checks configuration, not whether your key is valid. /lossless sends your request; it does not run Jev automatically.
